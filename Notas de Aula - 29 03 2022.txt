1. Conceitos Fundamentais de Banco de Dados

Dado: fato do mundo real que está registrado exemplos: endereço, data

Informação: fato útil que pode ser extraído direta ou indiretamente a partir dos dados exemplos: endereço de entrega, idade

Banco de Dados (BD): coleção de dados inter-relacionados e persistentes que representa um sub-conjunto dos fatos presentes em um domínio de aplicação(universo de discurso)
Podemos definir que Banco de Dados é um conjunto de dados específicos que possuem relação entre si, que gerem algum tipo de informação aos usuários, representando um Mini-Mundo de forma lógica e coerente.

Problemas Comuns:
   * Redundância de dados - Arquivos e programas são criados por diferentes programadores, 
   * Inconsistência - uma mesma informação, quando duplicada em diversos arquivos, eleva o custo de armazenamento e compromete a  sua consistência;
   * Dificuldade do acesso a dados - não permite acesso e manipulação dos dados de maneira eficaz;
   * Carência de padronização - dados são espalhados em vários arquivos de diferentes formatos.
   * Carência de controle de segurança – resulta no acesso indevido aos dados armazenados.

SGBD: Sistema Gerenciador de Banco de Dados. Um SGBD é uma ferramenta de auxílio à administração da Base de Dados, de forma a manter as regras da base e buscar as melhores maneiras para trabalhar com determinados dados.

Os bancos de dados mudam a medida que informações são inseridas ou apagadas
    A coleção de informações armazenadas é chamada de INSTÂNCIA do banco de dados (mudam com frequência) 
    O projeto geral do banco de dados é chamado ESQUEMA do banco de dados (não mudam com frequência)
	
	Fragmentação: dispersão quando a variedade de padrões.
	
	Volumetria: tamanho de dados (quantidade)
	
	Granularidade: nivel de detalhe

2.Comandos DDL e Comandos DML

Um esquema de banco de dados é especificado por um conjunto de definições expressas por uma linguagem especial chamada linguagem de definição de dados (Data Definition Language)
O resultado da compilação de comandos de uma DDL é o conjunto de tabelas que serão armazenadas no dicionário (ou diretório) de dados

Manipulação de Dados (DML). Manipulação de dados significa:
    A busca da informação armazenada no BD
    A inserção de novas informações no BD
    A eliminação de informações do BD
    A modificação dos dados armazenados no BD
    No nível físico precisamos definir algoritmos que permitam acesso eficiente aos dados
Uma consulta (QUERY) é um comando de busca de uma informação no BD
A parte da DML que busca informações é chamada LINGUAGEM DE CONSULTA

2.Volumetria e Granularidade

Grandes volumes de dados e suas relações complexas justificam a criação de estratégias específicas para gerencia-los.

Processo de Tomada de Decisão
    Dado --> Informação --> Conhecimento --> Inteligência

A idéia é que a volumetria diminua na medida que o processo de decisão tenha sua transição, reduzindo também a sua granularidade (número de registros e variações).

5. DW - Data Warehouse

Data Warehouse é uma coleção de dados orientados por assuntos, integrados, variáveis com o tempo e não voláteis, para dar suporte ao processo de tomada de decisão.

Usualmente, os data warehouses dão apoio a análises de série temporal e de tendências, as quais requerem maior volume de dados históricos do que os que geralmente são mantidos em bancos de dados transacionais.

	E - Extrair os dados
	T - Transformação dos dados (limpeza e normalização)
	L - Carga dos dados

6. Datamining
Mineração de Dados é um passo no processo de KDD que consiste na aplicação de análise de dados e algoritmos de descobrimento que produzem uma enumeração de padrões (ou modelos) particular sobre os dados.

Mineração de Dados: Prospecção de dados ou mineração de dados é o processo de explorar dados à procura de padrões consistentes, como regras de associação ou sequências temporais, para detectar relacionamentos sistemáticos entre variáveis, detectando assim novos subconjuntos de dados.

Muitos dados, alta volumetria, exige regras e critérios para tratar a granularidade e a quantidade de padrões.

Técnicas que são utilizadas
    Bancos de Dados
    Aprendizagem de Máquina
    Algoritmos para ordenação e recuperação de informações
    Aplicações especializadas
    Computação de alta performance
    Reconhecimento de Padrões
    Técnicas de DW
    Visualização 
    Estatística

7. Knowledge Discovery in Databases – KDD

Extração de conhecimento é um processo de extração de informações de base de dados, que cria relações de interesse que não são observadas pelo especialista no assunto, bem como auxilia a validação de conhecimento extraído. 

A) Conhecimento
    Definição do tipo de conhecimento a descobrir, o que pressupõe uma compreensão do domínio da aplicação, bem como do tipo de decisão que tal conhecimento pode contribuir para melhorar.

B) Seleção
    Criação de um conjunto de dados alvo (Selection): selecionar um conjunto de dados, ou focar num subconjunto, onde a descoberta deve ser realizada.


C) Limpeza de Dados
    Pré-processamento: operações básicas, tais como remoção de ruídos quando necessário, coleta da informação necessária para modelar ou estimar ruído, escolha de estratégias para manipular campos de dados ausentes,  formatação de dados de forma a adequá-los à ferramenta de mineração

D) Redução de Dados
    Projeção (Transformation): localização de características úteis para representar os dados dependendo do objetivo da tarefa,visando a redução do número de variáveis e/ou instâncias a serem consideradas para o conjunto de dados

E) Mineração de Dados (Datamining)    
    Selecionar os métodos a serem utilizados para localizar padrões nos dados, seguida da efetiva busca por padrões de interesse numa forma particular de representação ou conjunto de representações; busca pelo melhor ajuste dos parâmetros do algoritmo para a tarefa em questão.

F) Interpretação
    Interpretação dos padrões minerados (Interpretation/ Evaluation), com um possível retorno aos passos A até E para posterior iteração.

G) Implantação do conhecimento descoberto (Knowledge):
     Incorporar este conhecimento à performance do sistema, ou documentá-lo e reportá-lo às partes interessadas.

8. Problemas da Busca de Conhecimento
    Bases de dados são altamente suscetíveis a dados ruidosos erros e valores estranhos incompletos (valores de atributos ausentes) e inconsistentes (discrepâncias semânticas).
    Técnicas de pré-processamento e transformação de dados são aplicadas para aumentar a qualidade e o poder de expressão dos dados a serem minerados.
    Estas fases tendem a consumir a maior parte do tempo dedicado ao processo de KDD (aproximadamente 70%)
    Rotinas de limpeza de dados tentam suprir valores ausentes, reduzir discrepâncias de valores ruidosos e corrigir inconsistências.
    Alternativas
        - Ignorar a tupla
        - Suprir valores ausentes
            a) manualmente;
            b) através de uma constante global;
            c) utilizando a média do atributo;
            d) utilizando a média do atributo para todas as instâncias da mesma classe;
            e) com o valor mais provável (regressão, inferência etc.).
